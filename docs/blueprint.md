# **App Name**: Emission Tracker

## Core Features:

- Facility Selection: Allow users to select a specific facility from a list.
- Fuel Type Selection: Provide a selection screen for fuel types (LPG, CNG, Natural Gas, Diesel).
- Emission Value Display: Display CO2, CO, NOx, and O2 emission values for the selected facility and fuel type.
- Realtime Database Synchronization: Connect and synchronize with Firebase Realtime Database to fetch and display live data.

## Style Guidelines:

- Primary color: Turquoise (#40E0D0) to represent clean energy and monitoring.
- Background color: Light gray (#F0F0F0) for a clean and neutral backdrop.
- Accent color: Dark gray (#A9A9A9) for contrast and emphasis on important elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, neutral look suitable for both headlines and body text.
- Use minimalist icons to represent different facilities, fuel types, and emission values.
- Employ a clean, card-based layout to present data in an organized and easily digestible manner.
- Incorporate subtle transition animations for data updates to enhance user experience.
